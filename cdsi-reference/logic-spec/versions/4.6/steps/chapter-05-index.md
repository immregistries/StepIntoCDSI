## Source

Logic Specification for ACIP Recommendations v4.6, page 41 (chapter overview only). Table 5-1 (Create Relevant Patient Series Process Steps), Figure 5-1 (Create Relevant Series Process Model).

## Overview

**[SPEC]** "The antigen Supporting Data defines one or more antigen series for each antigen. Before beginning the evaluation process for a given patient, a set of relevant patient series must first be selected and created for the patient... The appropriateness of an antigen series is based on criteria such as patient gender, age, and underlying conditions." This chapter has a single subsection (5.1); Table 5-1 lists it as the chapter's only activity.
