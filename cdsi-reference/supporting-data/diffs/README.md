# Supporting Data diffs

Generated by `supporting-data compare --from <old> --to <new>` (Phase 15) - each comparison writes a pair of files here:

```text
<old>-to-<new>.md      # human-readable change report, grouped by category with a summary count
<old>-to-<new>.json    # machine-readable companion - every entry links back to its source and normalized files
```

Generated, not hand-maintained - safe to regenerate from the two registered, normalized releases at any time. See `supporting-data/README.md`'s "Comparing two releases" for what's compared, what stable identifiers are used, and what's deliberately out of scope.
