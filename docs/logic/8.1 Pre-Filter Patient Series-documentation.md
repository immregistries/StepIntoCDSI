## Chapter Text

Pre - filter patient series examines each of the patient series for a given Series Group to determine if any series should be removed from consideration for best patient series. If a Series Group contains relevant patient series of different priorities, only the set of highest prior ity patient series should be considered when determining the best patient series for the Series Group.
