# Chapter 4.4: Evaluate and Forecast All Patient Series

## Summary
Main evaluation and forecasting engine that processes each target dose across all patient series. Implements complex state management with loop guards to prevent infinite cycles during the evaluate/forecast handoff process.

## Methods
- `process(): LogicStep` — Core state machine orchestrating evaluation and forecasting logic; manages neighborhood states and cycle counting
- `buildLoopSignature(): String` — Creates diagnostic signature for loop detection
- `finalizeStep(LogicStepType): LogicStep` — Validates cycle counts and enforces cycle limits (MAX_TOTAL_CYCLES=1000, MAX_REPEATED_STATE_CYCLES=200)

## ConditionAttributes Evaluated
- PatientSeries (current being evaluated)
- TargetDose (current target dose)
- AntigenAdministeredRecord (for evaluation)
- TargetDoseStatus
- EvaluationStatus

## Key Data Structures
- `PatientSeries` — Patient-specific vaccination series
- `TargetDose` — Individual target dose in series
- `AntigenAdministeredRecord` — Administered vaccines for comparison
- `Stepper<PatientSeries>` — Position tracking in patient series
- `Neighborhood` — State management for evaluate/forecast coordination

## Cycle Guard Alerts
- MAX_PROCESS_CALLS: Exceeding 1000 cycles forces transition to SELECT_BEST_PATIENT_SERIES
- LOOP_DETECTED: Repeating same state 200+ times forces safe exit
