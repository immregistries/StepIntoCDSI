# Chapter 4.6: Identify and Evaluate Vaccine Group

## Summary
Iterates through vaccine groups (e.g., MMR, DTaP) and applies vaccine group-specific forecasting rules. Merges antigen-based forecasts into vaccine group forecasts for final recommendations.

## Methods
- `process(): LogicStep` — Increments vaccine group position; processes vaccine group at current position or transitions to END when all groups processed
- `printPre(PrintWriter): void` — Standard pre-processing output
- `printPost(PrintWriter): void` — Standard post-processing output
- `printStandard(PrintWriter): void` — Common output for both pre and post

## ConditionAttributes Evaluated
- VaccineGroup (current position)
- VaccineGroupList (all vaccine groups)
- VaccineGroupPos (iteration position)

## Key Logging
- IDANDEVAL_VG control logs: Position and list size tracking
- STATE logs: Vaccine group processing details
- Warnings: Missing vaccine group information

## Key Data Structures
- `VaccineGroup` — Multi-antigen vaccine (e.g., MMR, DTaP, Tdap)
- `VaccineGroupList` — All vaccine groups for patient
- `VaccineGroupForecast` — Forecast for vaccine group

## Processing Rules
- Vaccine groups with multiple antigens require coordinated forecasting
- Single antigen vaccines handled separately
