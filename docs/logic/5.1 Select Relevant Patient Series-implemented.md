# Chapter 5.1: Select Relevant Patient Series

## Summary
Evaluates indications and creates patient series for each AntigenSeries of a selected antigen. Uses logic tables (LT54, LT55) to evaluate gender requirements, active observations, and age-based indication ranges.

## Methods
- `process(): LogicStep` — Evaluates logic tables then transitions to CREATE_RELEVANT_PATIENT_SERIES
- `printPre(PrintWriter): void` — Displays antigen selection information and series table
- `printPost(PrintWriter): void` — Displays logic tables and included patient series

## ConditionAttributes Evaluated
- Patient gender (caGender)
- Patient date of birth (caDateOfBirth)
- Active patient observations (caActivePatientObservations)
- Required gender from series (caRequiredGender)
- Series type (caSeriesType)
- Observation code (caObservationCode)
- Assessment date (caAssessmentDate)
- Indication begin age date (CALCDTIND-1)
- Indication end age date (CALCDTIND-2)

## Logic Tables
- **LT55** — Outer logic table for antigen series
- **LT54** — Inner logic table for indications within series (evaluates gender match, observation match, age range match)

## Key Data Structures
- `AntigenSeries` — Series definitions for target disease
- `Indication` — Indications within series
- `PatientSeries` — Patient-specific series created
- `ConditionAttribute` — Custom attributes for logic evaluation
