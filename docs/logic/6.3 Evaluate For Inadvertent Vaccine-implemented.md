# Chapter 6.3: Evaluate For Inadvertent Vaccine

## Summary
Checks if administered vaccine is marked as inadvertent for the target dose. Inadvertent vaccines are valid doses that fulfill immunization requirements despite being administered for other indications.

## Methods
- `process(): LogicStep` — Evaluates inadvertent vaccine logic table, sets target dose status, transitions to EVALUATE_AGE
- `printPre(PrintWriter): void` — Displays standard inadvertent vaccine explanation
- `printPost(PrintWriter): void` — Displays standard inadvertent vaccine explanation
- `printStandard(PrintWriter): void` — Common display logic

## ConditionAttributes Evaluated
- Vaccine dose administered (caVaccineDoseAdministered)
- Inadvertent vaccine type (caInadvertentVaccine)
- Inadvertent vaccine list from target dose

## Outcomes
- **YES**: Vaccine marked inadvertent, dose SATISFIED, continues to next evaluation
- **NO**: Continues to age evaluation
