# Chapter 7.5: Generate Forecast Dates and Recommended Vaccines

## Summary
Generates forecast dates (earliest, latest, recommended) and identifies vaccine types recommended for the next dose based on target dose requirements and patient age.

## Methods
- `process(): LogicStep` — Evaluates vaccine type logic, calculates forecast dates, populates forecast details
- Date calculation helpers: `findMinimumAgeDate()`, `findMaximumAgeDate()`, `findEarliestRecommendedAgeDate()`, `findLatestRecommendedAgeDate()`, `findEarliestRecommendedIntervalDates()`, etc.

## ConditionAttributes Evaluated
- Minimum age date (caMinimumAgeDate, from 6.4)
- Earliest recommended age date (caEarliestRecommendedAgeDate)
- Latest recommended age date (caLatestRecommendedAgeDate)
- Maximum age date (caMaximumAgeDate)
- Minimum interval dates (caMinimumIntervalDates)
- Earliest recommended interval dates (caEarliestRecommendedIntervalDates)
- Latest recommended interval date (caLatestRecommendedIntervalDate)
- Latest conflict end interval date (caLatestConflictEndIntervalDate)
- Seasonal recommendation start date (caSeasonalRecommendationStartDate)
- Vaccine type (caVaccineType)
- Forecast vaccine type (caForecastVaccineType)

## Date Calculation Rules
- **Earliest Date**: Maximum of (minimum age, earliest interval, absolute minimum)
- **Recommended Date**: Maximum of (earliest recommended age, earliest recommended interval)
- **Latest Date**: Minimum of (latest recommended age, maximum age)
- **Latest Interval Date**: From conflict windows or interval rules

## Recommended Vaccines
- Prefer preferable vaccine types for target dose
- Fall back to allowable vaccines if preferred unavailable
- Consider age, manufacturer, volume constraints

## Key Data Structures
- `SeriesDose` — Source of age/interval requirements
- `Interval` — Spacing requirements between doses
- `TimePeriod` — Age and interval periods
