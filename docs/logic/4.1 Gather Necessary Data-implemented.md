# Chapter 4.1: Gather Necessary Data

## Summary
Gathers patient demographics, immunization history, and observations from the assessment request. Parses CVX/MVX vaccine codes and condition flags, then constructs domain objects for subsequent processing.

## Methods
- `process(): LogicStep` — Parses HTTP request parameters, creates Patient and ImmunizationHistory objects, populates vaccine doses and observations, then transitions to next step
- `printPre(PrintWriter): void` — Pre-processing output
- `printPost(PrintWriter): void` — Post-processing output

## ConditionAttributes Evaluated
- Patient date of birth (PARAM_PATIENT_DOB)
- Patient gender/sex (PARAM_PATIENT_SEX)
- Assessment date (PARAM_EVAL_DATE)
- Vaccine CVX code (PARAM_VACCINE_CVX)
- Vaccine MVX/manufacturer (PARAM_VACCINE_MVX)
- Vaccine administration date (PARAM_VACCINE_DATE)
- Dose condition flag (PARAM_VACCINE_CONDITION_CODE)
- Observation codes (PARAM_OBSERVATION_CODE)
- Observation dates (PARAM_OBSERVATION_DATE)

## Key Data Structures
- `Patient` — Contains date of birth, gender, medical history, receives list
- `ImmunizationHistory` — Collection of VaccineDoseAdministered records
- `VaccineDoseAdministered` — Individual vaccine doses with date, CVX, MVX, condition flag
- `PatientObservation` — Medical observations with code and date
- `VaccineType` (from CVX map) — Vaccine type reference
