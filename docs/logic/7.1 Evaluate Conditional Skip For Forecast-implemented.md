# Chapter 7.1: Evaluate Conditional Skip For Forecast

## Summary
Determines if a target dose can be skipped during forecasting phase based on conditional skip rules. Inherits from EvaluateConditionalSkip with forecast-specific parameters.

## Methods
- `process(): LogicStep` — Evaluates conditional skip logic [inherited from parent]
- `printPre(PrintWriter): void` — Displays standard skip rules explanation
- `printPost(PrintWriter): void` — Displays standard skip rules explanation

## ConditionAttributes Evaluated (inherited)
- Date administered (caDateAdministered)
- Administered dose count (caAdministeredDoseCount)
- Assessment date (caAssessmentDate)
- Earliest date (caEarliestDate)

## Configuration
- ConditionalSkipType: FORECAST
- NoSkipLogicStep: DETERMINE_EVIDENCE_OF_IMMUNITY
- SkipLogicStep: EVALUATE_AND_FORECAST_ALL_PATIENT_SERIES

## Conditional Skip Scenarios (Forecast Phase)
- Catch-up doses where patient is current
- Patient behind schedule - doses can be reduced
- Catch-up opportunities
- Administrative convenience rules

## Skip Determination
- Evaluates conditional skip rules from supporting data
- Each rule = set of conditions (AND/OR within set)
- Multiple sets (AND/OR across sets)
- If conditions met: Skip target dose, move to next

## Next Step
→ 7.2 Determine Evidence of Immunity (if not skipped) or 4.4 Evaluate And Forecast All Patient Series (if skipped)

## Key Dependencies
- EvaluateConditionalSkip (parent class)
- TargetDose conditional skip attributes
- Supporting data conditional skip rules
