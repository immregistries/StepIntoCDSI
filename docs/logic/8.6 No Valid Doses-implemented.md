# Chapter 8.6: No Valid Doses

## Summary
Scores patient series that have no satisfied doses, based on earliest start date and maximum age constraints. Enables recommendation for patients with no prior vaccination history.

## Methods
- `process(): LogicStep` — Evaluates no valid dose scoring conditions [partial implementation]
- `evaluate_AScorablePatientSeriesCanStartEarliest()`: Scores by earliest forecast date
- `addTimePeriodtotoDate()`: Helper for date calculations
- `findMaximumAgeDate()`: Helper for age constraints

## Scoring Criteria
1. Can series start earliest?
   - Series with earliest forecast date scores higher
   - Multiple series with same earliest date: Count ties

2. Can complete before maximum age?
   - Series that can complete within age limit scores higher
   - Series with later maximum age has more flexibility

3. Default/routine preference
   - Default series scored higher if all else equal

## Earliest Date Calculation
- From series dose requirements
- Based on patient age at assessment
- Considering minimum age and interval constraints

## Key Data Structures
- `PatientSeries` — Series with NO_VALID_DOSES status
- `Forecast` — Forecast with earliest date
- `SeriesDose` — Age and interval requirements
- `TimePeriod` — Age periods

## Scoring Output
- Series with earliest feasible start date scored higher
- Series scorable despite no prior doses
- Supports "start from scratch" scenarios
