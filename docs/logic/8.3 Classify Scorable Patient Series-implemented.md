# Chapter 8.3: Classify Scorable Patient Series

## Summary
Attempts to reduce candidate patient series count to only those with real chance of being selected as best series. Classifies by status and applies preliminary scoring.

## Methods
- `process(): LogicStep` — Classifies patient series by status and dose counts; filters relevant series; transitions to NO_VALID_DOSES
- `calculateCompletePatientSeriesCount()`: Counts COMPLETE status series
- `calculateCountOfPatientSeriesWithValidDoses()`: Counts series with satisfied doses
- `printStandard(PrintWriter): void` — Displays classification logic

## Classification Categories
- **COMPLETE**: All required doses satisfied
- **IN_PROCESS**: Some doses satisfied, series ongoing
- **NO_VALID_DOSES**: No satisfied doses
- **CONTRAINDICATED**: Cannot receive vaccine

## Filtering Logic
1. Count complete series with valid doses
2. If any complete series: Focus on those
3. If no complete: Evaluate in-process series
4. If no valid doses: Handle separately

## Scoring Rules
- Complete series with most valid doses scored higher
- In-process series scored by progress
- No valid dose series scored lowest

## Key Data Structures
- `PatientSeries` — Scorable candidates with status
- `PatientSeriesStatus` — COMPLETE, IN_PROCESS, NO_VALID_DOSES
- `TargetDose` — Dose satisfaction tracking
- Series scoring fields
