# Chapter 6.2: Evaluate Conditional Skip For Evaluation

## Summary
Determines if a target dose can be skipped during evaluation phase based on conditional skip rules. Inherits from EvaluateConditionalSkip with evaluation-specific parameters.

## Methods
- `process(): LogicStep` — Evaluates conditional skip logic [inherited from parent]
- `printPre(PrintWriter): void` — Displays standard skip rules explanation
- `printPost(PrintWriter): void` — Displays standard skip rules explanation

## ConditionAttributes Evaluated (inherited)
- Date administered (caDateAdministered)
- Administered dose count (caAdministeredDoseCount)
- Assessment date (caAssessmentDate)
- Earliest date (caEarliestDate)

## Conditional Skip Scenarios
1. Catch-up doses where patient is current (no need to catch up)
2. Patient behind schedule - total doses needed can be reduced
3. Previously administered dose(s) negate current target dose need

## Skip Rules Evaluation
- Each skip rule is a set of conditions
- Within a set: Multiple conditions use condition logic (AND/OR)
- Across sets: Multiple sets use set logic (AND/OR)
- Dose may be skipped if one or more sets evaluate to true

## Configuration
- ConditionalSkipType: EVALUATE
- NoSkipLogicStep: EVALUATE_FOR_INADVERTENT_VACCINE
- SkipLogicStep: EVALUATE_AND_FORECAST_ALL_PATIENT_SERIES
