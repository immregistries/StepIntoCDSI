# Chapter 8.8: Determine Best Patient Series

## Summary
Final determination of best patient series for each antigen within a vaccine group. Applies comprehensive logic table to confirm prioritized series is truly the best choice.

## Methods
- `process(): LogicStep` — Evaluates best series logic table for each prioritized series matching current antigen; transitions to SELECT_BEST_PATIENT_SERIES
- `printStandard(PrintWriter): void` — Displays antigen and logic tables

## Series Equivalence
- Equivalent series groups: Different paths to same disease immunity
- Example: IPV vs OPV for polio
- If multiple equivalent complete series: Choose best among them

## Best Series Determination
- COMPLETE series preferred over IN_PROCESS
- If multiple COMPLETE: Already scored and selected
- If no COMPLETE: IN_PROCESS is best available
- If no valid series: NO_VALID_DOSES default
