# Chapter 4.3: Create Relevant Patient Series

## Summary
Determines which antigens to forecast for based on request parameters or filter list, then iterates through each selected antigen to create relevant patient series for evaluation and forecasting.

## Methods
- `process(): LogicStep` — Manages antigen selection and iteration; creates antigen selected list on first run or increments position on subsequent runs; transitions to SELECT_RELEVANT_PATIENT_SERIES for each antigen or to EVALUATE_AND_FORECAST_ALL_PATIENT_SERIES when complete
- `printPre(PrintWriter): void` — Displays antigen selection checkboxes

## ConditionAttributes Evaluated
- Antigen label filter (from DataModel)
- Request parameters for antigen inclusion
- TestCaseRegistered flag for batch processing

## Key Data Structures
- `Antigen` — Disease antigen being evaluated
- `AntigenSeries` — Series paths for target disease
- `PatientSeries` — Patient-specific series instances
- `AntigenSelectedList` — Filtered list of antigens for forecasting

## Logic Flow
1. First execution: Create antigenSelectedList (filtered or all antigens)
2. If no antigens selected: Use all available antigens
3. Subsequent executions: Increment antigen position
4. When position < list size: Go to SELECT_RELEVANT_PATIENT_SERIES for that antigen
5. When position >= list size: Go to EVALUATE_AND_FORECAST_ALL_PATIENT_SERIES

## Next Step
→ 5.1 Select Relevant Patient Series (or 4.4 if all antigens processed)
