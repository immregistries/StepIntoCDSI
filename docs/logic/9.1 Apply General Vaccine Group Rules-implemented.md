# Chapter 9.1: Apply General Vaccine Group Rules

## Summary
Initial vaccine group classification step that determines whether vaccine group contains single or multiple antigens. Routes to appropriate vaccine group-specific processing logic.

## Methods
- `process(): LogicStep` — Evaluates vaccine group antigen count logic table; transitions to SINGLE_ANTIGEN_VACCINE_GROUP or MULTIPLE_ANTIGEN_VACCINE_GROUP
- `printStandard(PrintWriter): void` — Displays classification explanation and logic tables

## Logic Table: TABLE 7-2 WHAT IS THE VACCINE GROUP TYPE?

| Condition | Result |
|-----------|--------|
| Does vaccine group contain exactly 1 antigen? | YES/NO |

## Outcomes
- **YES (1 antigen)**: Transition to SINGLE_ANTIGEN_VACCINE_GROUP
  - Single Antigen Vaccine Group processing
  - Direct forecast from antigen-level forecast
  
- **NO (>1 antigen)**: Transition to MULTIPLE_ANTIGEN_VACCINE_GROUP
  - Multiple Antigen Vaccine Group processing
  - Aggregates multiple antigen forecasts

## Examples
- Single antigen: Polio (only OPV/IPV), Rotavirus (only RV)
- Multiple antigen: MMR (measles, mumps, rubella), DTaP (diphtheria, tetanus, pertussis)

## Key Data Structures
- `VaccineGroup` — Current vaccine group
- `Antigen` — Antigens in group
- `VaccineGroupForecast` — Forecast being constructed
