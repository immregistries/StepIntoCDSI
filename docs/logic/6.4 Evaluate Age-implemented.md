# Chapter 6.4: Evaluate Age

## Summary
Validates the age at vaccine administration against defined age requirements for target dose. Checks absolute minimum age, minimum age, and maximum age constraints.

## Methods
- `process(): LogicStep` — Evaluates age logic table, sets evaluation status, transitions to EVALUATE_PREFERABLE_INTERVAL
- `printPre(PrintWriter): void` — Displays age validation explanation
- `printPost(PrintWriter): void` — Displays age validation explanation
- `printStandard(PrintWriter): void` — Common display logic

## ConditionAttributes Evaluated
- Date of birth (caDateOfBirth)
- Date administered (caDateAdministered)
- Minimum age date (caMinimumAgeDate, calculated)
- Maximum age date (caMaximumAgeDate, calculated)
- Absolute minimum age date (caAbsoluteMinimumAgeDate, calculated)

## Age Ranges (from SeriesDose)
- Absolute minimum age (never valid before)
- Minimum age (preferred minimum)
- Maximum age (latest allowable age)

## Logic Flow
1. Calculate dates from age time periods and DOB
2. Validate date administered against age range
3. Mark evaluation as VALID, CONDITIONALLY_VALID, or SUB_STANDARD

## Key Logic
- If no age constraints: Age considered VALID
- Administered before minimum age: SUB_STANDARD
- Within minimum to maximum: VALID
- After maximum age: Invalid or conditionally valid
