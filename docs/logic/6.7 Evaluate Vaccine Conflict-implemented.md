# Chapter 6.7: Evaluate Vaccine Conflict

## Summary
Detects live virus vaccine conflicts, particularly important for vaccines like MMR and varicella. Prevents administration of multiple live virus vaccines within restricted time periods.

## Methods
- `process(): LogicStep` — Evaluates nested logic tables (LT420, LT421, LT422) for live virus conflicts; transitions back to EVALUATE_AND_FORECAST_ALL_PATIENT_SERIES
- `printPre(PrintWriter): void` — Pre-processing output
- `printPost(PrintWriter): void` — Post-processing output

## ConditionAttributes Evaluated
- Current vaccine type (caCurrentVaccineType)
- Previous vaccine types (caPreviousVaccineType)
- Conflict begin interval date (CALCDTLIVE-1)
- Conflict end interval date (CALCDTLIVE-2, CALCDTLIVE-3)
- Date administered

## Live Virus Conflict Logic Tables
- **LT420**: Is current vaccine a live virus vaccine?
- **LT421**: Is previous vaccine a live virus vaccine?
- **LT422**: Is conflict within interval?

## Conflict Resolution
- If both current and previous are live virus vaccines
- Calculate conflict window dates
- If current vaccine within conflict window of previous: Conflict detected
- Mark dose as invalid or conditionally valid

## Key Dependencies
- VaccineType (live virus attribute)
- LiveVirusConflict definitions
- AntigenAdministeredRecord (for previous doses)
- Date calculations (CALCDTLIVE-1, CALCDTLIVE-2, CALCDTLIVE-3)
