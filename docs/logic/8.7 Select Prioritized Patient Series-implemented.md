# Chapter 8.7: Select Prioritized Patient Series

## Summary
Selects the single highest-scored patient series from scorable candidates as the prioritized series for the antigen.

## Methods
- `process(): LogicStep` — Scores series, selects highest scoring series, adds to prioritized list, transitions to DETERMINE_BEST_PATIENT_SERIES
- `selectPrioritizedPatientSeries()`: Main selection logic
- `numberOfValidDoses()`: Helper for score evaluation

## Selection Logic
1. Initialize with first series in list
2. Iterate through all scorable series
3. Compare scores:
   - Higher score = new best candidate
   - Equal score: Check series preference (lower number = higher priority)
4. Select series with highest score and best preference

## Tie-Breaking
- If series have equal scores:
  - Compare series preference value
  - Lower preference number = higher priority
  - Update selection if new series has lower preference

## Output
- Single prioritized patient series identified
- Added to prioritizedPatientSeriesList
- Ready for best series determination

## Key Data Structures
- `PatientSeries` — Candidates with scores
- `ScorePatientSeries` — Numerical score value
- `SeriesPreference` — Preference ranking
- `PrioritizedPatientSeriesList` — Output
