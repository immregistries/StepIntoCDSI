# Chapter 7.2: Determine Evidence of Immunity

## Summary
Evaluates if patient has evidence of immunity against the target disease through prior vaccination, laboratory evidence, or disease history. Creates Forecast object for current antigen.

## Methods
- `process(): LogicStep` — Creates forecast object, evaluates immunity logic tables, transitions to DETERMINE_CONTRAINDICATIONS
- `printPre(PrintWriter): void` — Displays immunity evaluation explanation
- `printPost(PrintWriter): void` — Displays immunity evaluation explanation
- `printStandard(PrintWriter): void` — Common display logic

## ConditionAttributes Evaluated
- Date of birth (caDateofBirth)
- Country of birth (caCountryofBirth)
- Evidence of immunity (caEvidenceOfImmunity)
- Immunity elements (caImmunityElements)

## Immunity Sources
- Prior vaccination records (evaluated doses)
- Laboratory evidence (serology, titers)
- Birth date immunity (e.g., age-based presumptive immunity)
- Disease history from observations

## Logic Table: Table 7-2 Immunity Attributes

Evaluates:
1. Does patient have documented immunity evidence?
2. Is evidence valid/current?
3. Does evidence satisfy requirement?

## Key Data Structures
- `Forecast` — Created with antigen reference and target dose
- `Immunity` — Immunity requirements and sources
- `BirthDateImmunity` — Age-based presumptive immunity
- `PatientObservation` — Disease history records

## Outcomes
- Evidence of immunity = YES: Forecast marked as complete
- Evidence of immunity = NO: Continue to contraindication check
