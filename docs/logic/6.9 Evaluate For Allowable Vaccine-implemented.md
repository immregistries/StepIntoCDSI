# Chapter 6.9: Evaluate For Allowable Vaccine

## Summary
Evaluates whether administered vaccine is acceptable for the target dose. More permissive than preferable vaccine check; validates vaccine type, age, and other allowable criteria.

## Methods
- `process(): LogicStep` — Evaluates allowable vaccine logic tables; if at least one passes, marks as valid; otherwise marks status cause as "Vaccine"; transitions to SATISFY_TARGET_DOSE
- `printPre(PrintWriter): void` — Displays allowable vaccine evaluation
- `printPost(PrintWriter): void` — Displays allowable vaccine evaluation

## ConditionAttributes Evaluated (per allowable vaccine)
- Date administered (caDateAdministered)
- Vaccine type (caVaccineType)
- Allowable vaccine elements (caAllowableVaccineElements)
- Allowable vaccine type begin age date (CALCDTALLOW-1)
- Allowable vaccine type end age date (CALCDTALLOW-2)

## Allowable Vaccine Criteria
- Vaccine type acceptance
- Age range validation (begin and end dates)
- Any other allowable restrictions

## Processing
1. Iterate through allowable vaccine list per target dose
2. For each vaccine: Evaluate type match, age range
3. If any vaccine passes: atLeastOnePass = YES
4. If all fail: Mark status cause as "Vaccine", dose invalid
