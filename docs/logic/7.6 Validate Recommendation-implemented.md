- `process(): LogicStep` — Evaluates conditional skip validation logic, transitions to EVALUATE_AND_FORECAST_ALL_PATIENT_SERIES
- `printPre(PrintWriter): void` — Pre-processing output
- `printPost(PrintWriter): void` — Post-processing output

## Configuration
- ConditionalSkipType: VALIDATING
- NoSkipLogicStep: EVALUATE_AND_FORECAST_ALL_PATIENT_SERIES

## Validation Criteria
- Forecast dates are reasonable
- Vaccine recommendations are appropriate
- All prior logic rules satisfied
- Special validation rules pass

## Conditional Skip in Validation
- Can override forecast if certain conditions met
- Examples: Administrative convenience, patient preference considerations
- More restrictive than evaluation/forecast phases

- `ValidateRecommendation` extends `EvaluateConditionalSkip`

## Output
