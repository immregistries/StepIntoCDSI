## Chapter Text

Evaluate Dose Administered Condition checks the dose administered to see if the target dose must be repeated regardless of the other evaluation rules.

Relationship to ACIP recommendations: Doses which were administered after the lot expiration date or which contain a condition do not need to be evaluated.

Examples of conditions which would prevent evaluation of a vaccine dose administered range from misadministration to recalls to cold chain breaks.

The following processing model, attribute table and decision table are used to determine if dose administered can be evaluated.
