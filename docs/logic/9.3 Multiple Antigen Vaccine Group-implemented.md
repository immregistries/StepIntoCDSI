# Chapter 9.3: Multiple Antigen Vaccine Group

## Summary
Processes vaccine groups containing multiple antigens (e.g., MMR, DTaP). Aggregates forecasts from multiple antigen-level best patient series into cohesive vaccine group forecast using coordination rules.

## Methods
- `process(): LogicStep` — Filters best series for vaccine group antigens, evaluates vaccine group status logic, applies aggregation rules (MULTIANTVG-1 through MULTIANTVG-8), transitions to IDENTIFY_AND_EVALUATE_VACCINE_GROUP
- Multiple helper methods for aggregation rules (MULTIANTVG-1 through MULTIANTVG-8)

## Key Data Structures
- `VaccineGroup` — Multiple antigens
- `PatientSeries` — Best series (one per antigen)
- `VaccineGroupForecast` — Output aggregation
- `IntervalPriority` — Coordination between antigen forecasts

## Processing Steps
1. Filter best patient series for current vaccine group's antigens
2. Evaluate vaccine group status logic (complete, in-process, etc.)
3. Apply aggregation rules based on status

## Aggregation Rules (MULTIANTVG rules)
- **Status determination**: Aggregate antigen statuses into group status
- **Date aggregation**: Coordinate earliest, recommended, latest dates
- **Vaccine type selection**: Combine vaccine recommendations
- **Special handling**: For NOT_COMPLETE status

## Vaccine Group Status Determination
- ALL COMPLETE → COMPLETE
- ANY IN_PROCESS → IN_PROCESS (or better)
- ALL NO_VALID_DOSES → NO_VALID_DOSES
- CONTRAINDICATED handling

## Date Coordination (for NOT_COMPLETE)
- MULTIANTVG-1 through MULTIANTVG-8: Specific coordination rules
- Aggregate dates from individual forecasts
- Consider interval priorities between antigens

## Example: MMR Vaccine Group
- Measles antigen forecast
- Mumps antigen forecast
- Rubella antigen forecast
- → Combined MMR vaccine group forecast
