# Chapter 6.8: Evaluate For Preferable Vaccine

## Summary
Evaluates whether administered vaccine matches preferred vaccine types for the target dose, based on age and other factors. Identifies preferred options but doesn't invalidate other valid vaccines.

## Methods
- `process(): LogicStep` — Evaluates preferable vaccine logic for each vaccine in list; transitions to EVALUATE_FOR_ALLOWABLE_VACCINE
- `printPre(PrintWriter): void` — Displays preferable vaccine evaluation
- `printPost(PrintWriter): void` — Displays preferable vaccine evaluation

## ConditionAttributes Evaluated (per preferable vaccine)
- Date administered (caDateAdministered)
- Volume (caVolume)
- Trade name (caTradeName)
- Preferable vaccine elements (caPreferableVaccineElements)
- Vaccine type begin age date (CALCDTPREF-1)
- Vaccine type end age date (CALCDTPREF-2)

## Preferable Vaccine Criteria
- Specific vaccine type (by manufacturer/trade name)
- Volume requirements
- Age range restrictions
- Cost or clinical preference factors

## Logic Flow
1. Iterate through preferable vaccine list
2. For each vaccine: Check type match, volume, trade name
3. Evaluate age range (begin and end dates)
4. Mark as preferable match if all criteria met
5. Continue to allowable vaccine check if not preferred
