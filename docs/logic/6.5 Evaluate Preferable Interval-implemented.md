# Chapter 6.5: Evaluate Preferable Interval

## Summary
Validates interval(s) between current dose and previous dose(s) against preferable interval requirements. Multiple interval checks may be evaluated; all must pass for preferable satisfaction.

## Methods
- `process(): LogicStep` — Iterates through preferable interval logic tables; if all pass, transitions to EVALUATE_VACCINE_CONFLICT; otherwise to EVALUATE_ALLOWABLE_INTERVAL
- `printPre(PrintWriter): void` — Displays interval validation explanation
- `printPost(PrintWriter): void` — Displays interval validation explanation
- `printStandard(PrintWriter): void` — Common display logic

## ConditionAttributes Evaluated (per interval check)
- Date administered (caDateAdministered)
- Preferable interval elements (caPreferableIntervalElements)
- Absolute minimum interval date (CALCDTINT-3)
- Minimum interval date (CALCDTINT-4)

## Interval Logic
- Multiple intervals per series dose
- Each interval: Previous dose + interval period = minimum acceptable date
- Absolute minimum: Never before this date
- Minimum: Preferred minimum date
- Preferable satisfied: Dose on or after minimum date

## Processing
1. Create LT for each interval in series dose
2. Evaluate each interval check separately
3. If any interval fails (YesNo.NO): Mark preferable NOT satisfied
4. If all pass OR no intervals defined: Preferable satisfied

## Next Step
→ 6.6 Evaluate Vaccine Conflict (if satisfied) or 6.6 Evaluate Allowable Interval (if not satisfied)

## Key Dependencies
- SeriesDose interval list
- Previous AntigenAdministeredRecord
- Interval time periods
- Date calculations (CALCDTINT-3, CALCDTINT-4)
