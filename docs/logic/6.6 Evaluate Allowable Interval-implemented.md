# Chapter 6.6: Evaluate Allowable Interval

## Summary
Validates interval(s) between current dose and previous dose(s) against allowable (minimum acceptable) interval requirements. Applies only if preferable intervals not satisfied.

## Methods
- `process(): LogicStep` — Evaluates allowable interval logic tables; marks status cause if interval fails; transitions to EVALUATE_VACCINE_CONFLICT
- `printPre(PrintWriter): void` — Pre-processing output
- `printPost(PrintWriter): void` — Post-processing output

## ConditionAttributes Evaluated
- Date administered (caDateAdministered)
- Allowable interval elements (caAllowableIntervalElements)
- Absolute minimum interval date (CALCDTINT-3)

## Allowable Interval Logic
- Fallback check when preferable interval not met
- Less restrictive than preferable interval
- Represents minimum acceptable interval between doses
- Multiple allowable intervals may be defined

## Processing
1. Iterate through allowable interval list per series dose
2. For each interval: Calculate absolute minimum date
3. Evaluate if date administered meets minimum
4. If any interval fails (result = NO): Mark status cause as "Interval"
5. If all pass OR list empty: Continue
