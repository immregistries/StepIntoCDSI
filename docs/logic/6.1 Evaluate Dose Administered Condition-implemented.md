# Chapter 6.1: Evaluate Dose Administered Condition

## Summary
Validates whether a vaccine dose can be evaluated by checking lot expiration date and dose condition flag. Rejects doses administered after lot expiration or marked with special conditions.

## Methods
- `process(): LogicStep` — Evaluates logic table then transitions to EVALUATE_CONDITIONAL_SKIP_FOR_FORECAST
- `printPre(PrintWriter): void` — Pre-processing output
- `printPost(PrintWriter): void` — Post-processing output

## ConditionAttributes Evaluated
- Date administered (caDateAdministered)
- Lot expiration date (caLotExpirationDate, from CALCDTLOTEXP-1)
- Dose condition flag (caDoseCondition - YES/NO)

## Logic Table: Table 6-3 Can the vaccine dose administered be evaluated?

| Condition | Result 1 | Result 2 | Result 3 |
|-----------|----------|----------|----------|
| Date administered > lot expiration date? | YES | NO | NO |
| Is dose condition flag 'Y'? | ANY | YES | NO |
| **Outcome** | **Rejected** | **Rejected** | **Satisfied** |

## Outcomes
- **YES/ANY**: Dose rejected (expired lot), status set to NOT_SATISFIED
- **ANY/YES**: Dose rejected (condition flag), status set to NOT_SATISFIED
- **NO/NO**: Dose satisfies condition check, continues to next evaluation
