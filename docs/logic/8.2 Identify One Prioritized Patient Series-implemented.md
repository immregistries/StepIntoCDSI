# Chapter 8.2: Identify One Prioritized Patient Series

## Summary
Examines scorable patient series within a series group to identify one single prioritized series that is superior to all others. Uses logic table with scoring conditions.

## Methods
- `process(): LogicStep` — Evaluates logic tables to determine if single prioritized series exists; transitions to CLASSIFY_SCORABLE_PATIENT_SERIES
- `printStandard(PrintWriter): void` — Displays process description and logic tables

## Logic Table: Table 8-3 Is there a single prioritized patient series in a series group?

Conditions:
1. How many scorable patient series are in series group?
2. Is there a single best performing series?
3. Is prioritization clear?

Results: ZERO, ONE, MORE_THAN_ONE

## Scoring Criteria
- Valid doses count
- Series type (risk vs routine)
- Series preference ranking
- Completeness status
- No overlap in best indicators

## Outcomes
- **ZERO scorable series**: No prioritization needed, skip phase
- **ONE scorable series**: Clear prioritization, move to classification
- **MORE_THAN_ONE**: Multiple candidates, continue to scoring phase

## Key Data Structures
- `PatientSeries` — Scorable candidates
- `ScorablePatientSeriesList` — Input series set
- `AntigenSeries` — Series definitions with preferences
